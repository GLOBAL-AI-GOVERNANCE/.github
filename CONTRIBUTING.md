# Contributing

Contributions are welcome when they improve a repository within its stated scope and evidence boundary.

Before opening a pull request:

1. read the repository README and local contribution/security guidance;
2. keep the change bounded and explain why it is needed;
3. preserve existing public-claim and maturity boundaries;
4. add or update tests when behavior changes;
5. report validation that was actually run, including failures or skipped checks;
6. do not include secrets, personal data, proprietary material, or unauthorized third-party content.

A passing check proves only what that check tested. Human review remains responsible for interpretation and consequential decisions.
