# GLOBAL AI GOVERNANCE — GitHub Community Health

This repository provides account-level default community health and governance files for public repositories owned by `GLOBAL-AI-GOVERNANCE` when a repository does not define a local override.

It is infrastructure, not a product, framework, runtime, certification, or source of operational authority. Repository-specific files take precedence when local requirements differ.

## Purpose

- make contribution and support expectations consistent;
- establish a common security-reporting boundary;
- give issues and pull requests a predictable evidence-oriented structure;
- preserve repository-specific maturity, validation, and release controls.

See [GOVERNANCE.md](GOVERNANCE.md) and [docs/CHANGE_CONTROL.md](docs/CHANGE_CONTROL.md).
